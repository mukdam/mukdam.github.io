Project Overview

Nihal Fashion is an established online portal for traditional Indian ethnic wear (Sherwanis, Kurta Pyjamas, Sarees, etc.). This project focused on building a fully customizable product options module (custom stitching details, measurements, matching accessories) and optimizing load times for catalog pages.

Key Technical Achievements

  • • Dynamic Option Stitching Configurator: Engineered a tailored product attributes and custom options module inside Magento 2, enabling clients to submit sizing configurations which compile details directly into checkout payloads.
  • • Storefront Customizations: Reconstructed the product page interface using optimized HTML5, CSS3 transitions, and responsive structures.
  • • Code Integrity: Adhered to clean code parameters, utilizing strict Magento module standards and PSR standards.
