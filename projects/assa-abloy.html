SAP-Integrated B2B/B2C Commerce & Product Configurator

Adobe Commerce Magento 2 Enterprise Node.js Dell Boomi SAP ERP MDM AWS Redis

Project Overview

ASSA ABLOY is a global leader in access control, door hardware, and security solutions. This project involved migrating their legacy IBM WebSphere platform to a unified, multi-store Adobe Commerce (Magento) environment, consolidating 39+ country sites across 30+ regions, and syncing a complex shared catalog containing 110K+ products.

Key Architecture Decisions

  • • Dell Boomi Middleware: Engineered clean, robust SAP integration loops for real-time synchronization of MDM datasets, company structures, custom B2B pricing, and instant order tracking.
  • • SAP-driven Configurator: Replaced high-license external SaaS options with a custom product configurator built directly on the SAP API, enabling customers to configure locks and doors with dynamic prices determined in real time.
  • • Node.js Interceptor layer: Implemented lightweight Express microservices to intercept enterprise webhooks, cache dynamic query loads, and push analytics logs to monitoring systems.

Results & Achievements

  • ✓ Consolidated 39+ regional B2B domains into a single codebase and database instance.
  • ✓ Improved API throughput and reduced latencies by 30-40% using optimized query loops and custom Redis caching structures.
  • ✓ Established robust automated testing, linting, and zero/minimal downtime deployment workflows on Magento Cloud.
