MonitoringCarrier: ShipEngine Tracking Tool

Real-time multi-carrier tracking, shipment status telemetry, and logistics automation microservice powered by ShipEngine API, React.js, and Node.js.

ShipEngine API React.js Node.js / Express Carrier Telemetry Webhooks & REST APIs Adobe Commerce Integration

Executive Summary

MonitoringCarrier is an enterprise shipping operations and tracking tool engineered for global eCommerce ecosystems (such as ASSA ABLOY). By leveraging the ShipEngine API alongside a decoupled React frontend and Node.js backend microservice, MonitoringCarrier centralizes multi-carrier tracking (FedEx, UPS, DHL, USPS), automated shipment status telemetry, delivery exception alerts, and customer order status updates into a unified dashboard.

Key Architecture & Features

  • ShipEngine Tracking API Integration: Unified multiple carrier tracking services under a standardized REST API & Webhook handler, providing real-time tracking updates, estimated delivery dates, and package status history.
  • Interactive React Tracking Dashboard: Designed an intuitive, high-performance tracking portal for customer service managers and end users to look up order tracking numbers, view carrier timelines, and manage shipping notifications.
  • Node.js Event Telemetry & Alerting: Implemented Express.js middleware listening to ShipEngine webhooks for instant delivery exception alerts (delays, failed delivery attempts, address issues) and triggering automated transactional email/SMS notifications.
  • Adobe Commerce & SAP Integration: Seamlessly synced tracking data with Magento order records and SAP ERP via Dell Boomi middleware for end-to-end order lifecycle visibility across 30+ regional storefronts.

Business Impact & Results

  • ✓ Reduced WISMO ("Where Is My Order?") tickets by 45%: Automated real-time tracking updates drastically reduced customer inquiry calls.
  • ✓ Multi-Carrier Standardization: Abstracted carrier differences into a single normalized tracking JSON schema across FedEx, UPS, DHL, and local postal services.
  • ✓ High Throughput & Resilience: Built to process thousands of tracking webhooks per minute with Redis caching and asynchronous retry queues.
