Project Overview

Angara is a leading online jeweler specializing in colored gemstones, diamonds, and pearls. This project focused on migrating their core eCommerce system from legacy Magento 1.x to Magento 2.x, restructuring product catalogs, and optimizing frontend load speeds.

Key Technical Achievements

  • • Data Migration: Led the migration scripts to safely move customer records, historical transaction details, and product attribute matrices without data loss.
  • • Full Page Caching: Integrated Varnish Cache and Redis session clusters, lowering page response time and optimizing core web vitals.
  • • Catalog Restructuring: Designed flexible product options for gems, metal carats, and settings, resulting in a cleaner and faster checkout.
