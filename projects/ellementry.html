Node.js Reporting Engine & Magento REST API Integration

Node.js Express.js Magento 2 REST APIs MongoDB Redis

Project Overview

Ellementry is a prominent handcrafted homeware brand. The objective of this project was to establish an analytics and custom reporting service to gather sales data, customer behaviors, inventory metrics, and sync those details to dashboard dashboards.

Key Contributions

  • • Node.js microservice: Designed a standalone reporting service using Node.js and Express to fetch catalog information and compile complex business indicators.
  • • REST API development: Created custom Magento REST API endpoints designed to transfer database state logs directly to the reporting microservice without affecting front-end customer performance.
  • • Performance optimizations: Implemented MongoDB aggregation queries and cached processed reports inside Redis instances to avoid redundant load on database nodes.
